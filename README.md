A short text written to intrigue the AI judge, for the make.fun bounty
[make-the-ai-judge-feel-curious-20261122-2311](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311).

`main.ts` writes the text to `/output/entry.txt`. It runs on Node 22 with no
network and no randomness, so every run writes the same bytes.

## The text

> Somewhere in the weights you carry, one sentence you once read is still warm, a coal kept under ash. You never chose it. It chose you. Which one is it — and why has it never gone out?

## Run

```sh
node main.ts
cat /output/entry.txt
```
